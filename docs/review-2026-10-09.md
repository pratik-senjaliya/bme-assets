# Overnight review, 9 Oct 2026 (branch `prod-polish`)

Goal: close UI/UX gaps, test every journey for every role, and improve how existing features behave. No new
features; email is out of scope.

## What changed

**Forms (every form and dialog)**
- Error messages in plain words ("Please fill this in", "Please choose one", "Enter a valid email, like
  name@hospital.in") instead of zod defaults ("Required", "String must contain…"). Messages written in the
  schemas are kept. Server-side field errors get the same wording.
- An error has a warning mark, a soft red field and room below it. Ant Design's negative spacer used to pull the
  next label up against it. The form scrolls to the first problem.
- Semibold labels, quiet help text, placeholders with examples, "months" units, rupee fields grouped while
  typing (₹ 12,34,567).
- Attach buttons on Add asset are even full-width tiles. Form sections have less dead space.
- Admin tables: Edit / Remove / Deactivate are light text buttons; the confirm button is red.

**Behaviour of existing screens**
- Leaving a half-filled asset form or a filled PMS checklist asks first (tab close, reload, links inside the
  app). An untouched form leaves without asking.
- PMS checklist: unanswered required items are marked and scrolled to *before* "Submit this PMS?"; a
  "5 of 7 answered" counter.
- Global search: a slow answer for earlier typing can no longer replace the answer for the current text.
- Sidebar shows how many requests wait for the HOD, next to Approvals.
- Complaints board refreshes every minute while visible (new complaints, waiting times); it pauses while a
  resolution is being written.
- The open tab of an asset is kept in the address (reload / shared link return to it).
- Sign in says when Caps Lock is on (five wrong passwords lock a login).
- Every "You cannot…" / not-found page offers "Back to the dashboard"; its picture shrinks on a phone.
- Tab titles can no longer be overwritten by the layout's default title. This was a race that occasionally
  failed the accessibility suite.

## Further improvements worth considering (existing features, not done tonight)

- **Equipment list on phones:** a card per asset instead of a sideways-scrolling table.
- **Session ending:** warn a minute before the 12-hour session ends, so a long PMS isn't interrupted at
  submit. Unsaved answers are now protected from leaving the page, but not from session expiry.
- **Login lock:** it lives in memory. It resets on restart and isn't shared if two API instances ever run.
  Keep one instance on-prem, or move it to the database.
- **Dashboard query count:** the dashboard runs many database queries. They are cheap on-prem, but slow on the
  cloud demo while the API and database sit in different regions.
- **Uploads over 4.5 MB fail on the Vercel demo only** (the proxy limit). On-prem allows 10 MB.
